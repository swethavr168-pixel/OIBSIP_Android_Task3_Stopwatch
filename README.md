# OIBSIP_Android_Task3_Stopwatch
Android Stopwatch app using Java &amp; XML that measures time with start, stop, and reset functionality – OIBSIP Internship Task.

## 📖 Overview
This is a simple Android Stopwatch application developed as part of the Oasis Infobyte Internship Program (OIBSIP) under the Android Development domain. The app allows users to measure elapsed time with precise control using start, stop, and reset functions.

---

## 🎯 Objective
The objective of this project is to build a functional stopwatch application using Android Studio while understanding timing logic, UI updates, and event-driven programming in Android.

---

## 🚀 Features
- Start timer
- Stop timer
- Reset timer
- Lap time tracking (if implemented)
- Accurate time measurement (seconds/milliseconds)
- Clean and responsive UI

---

## 🛠️ Technologies Used
- Java
- XML
- Android Studio

---

## 📂 Project Structure
- `MainActivity.java` → Handles stopwatch logic and timer control  
- `activity_main.xml` → Main UI layout  
- `item_lap.xml` → Layout for displaying lap times  
- `res/drawable` → UI backgrounds and icons  
- `res/values` → Colors, strings, and themes  
- `AndroidManifest.xml` → App configuration
